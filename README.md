# Telegram Trends MCP — локальный комплект

Бесплатный сборщик публичных Telegram-каналов на базе `shadow-tg`. Он не использует Telegram-аккаунт, номер телефона, Bot API или MTProto-сессию: читает только публичные страницы `t.me/s/...`.

## Быстрый запуск в Windows

1. Распакуйте комплект, например в `C:\telegram-trends-mcp`.
2. Откройте PowerShell в этой папке.
3. Выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Если Python 3.11/3.12 отсутствует, установщик автоматически поставит Python 3.12 через `winget` для текущего пользователя. Если `winget` недоступен, установите Python с https://www.python.org/downloads/windows/ и отметьте `Add Python to PATH`.

Наличие одного только системного `py.exe` не считается установленным Python: установщик пропустит пустой launcher и автоматически перейдёт к установке Python 3.12.

4. Соберите первый отчёт за 48 часов:

```powershell
powershell -ExecutionPolicy Bypass -File .\collect.ps1 -Hours 48
```

Результаты появятся в папке `output`: `latest.md` для чтения и `latest.json` для последующего анализа моделью.

В отчёте отдельно показываются покрытие источников, повторяющиеся сюжеты и горячие публикации. Сюжеты строятся по именам и устойчивым словосочетаниям; вероятная реклама, пустые медиапосты и служебные подписи каналов не участвуют в рейтинге.

## Подключение как MCP

После установки отредактируйте `mcp-config.example.json`: замените `C:\FULL_PATH\telegram-trends-mcp` на полный путь к распакованной папке. Добавьте блок `mcpServers` в конфигурацию MCP-клиента.

Сервер предоставляет инструменты:

- `get_posts`;
- `search_posts`;
- `resolve_channel`;
- `search_channels`;
- `inspect_channels`;
- `get_channel`;
- `get_post`;
- `get_media`;
- `get_comments`.

Пример запроса к AI-клиенту после подключения:

> Возьми каналы из watchlist.json, собери посты за последние 48 часов. Найди темы, которые повторяются минимум в двух каналах, учти просмотры и возраст публикации. Отдельно предложи пять идей для Dead Inside в авторском, ироничном и интеллектуальном стиле.

## Watchlist

Каналы разделены на три типа:

- `core` — устойчивые тематические источники;
- `niche` — небольшие, но особенно близкие по стилю;
- `accelerator` — крупные каналы для раннего обнаружения массового сюжета, их вес понижен.

Военно-политический канал в конфигурации оставлен выключенным, чтобы геополитика не захватывала весь отчёт. Для включения поменяйте `enabled` на `true` в `watchlist.json`.

## Ограничения

- Это наблюдение за выбранной корзиной каналов, а не всем Telegram.
- `search_posts` ищет только среди последних постов конкретного канала.
- Доступность зависит от открытия `https://t.me/s/durov` в вашей сети.
- Публичная HTML-разметка Telegram может измениться и потребовать обновления пакета.
- В `shadow-tg 0.1.0` не закреплена верхняя версия MCP SDK. В `requirements.txt` уже добавлено совместимое ограничение `mcp<2`.

Локальный stdio-MCP можно подключить к Claude Desktop, Cursor, VS Code и другим локальным MCP-клиентам. Для прямого подключения к облачному клиенту потребуется отдельно разместить сервер с HTTP-транспортом.
